# Fingerprint Classification using FLANN and Genetic Algorithm

## 📌 Overview
This project implements a fingerprint classification system using a hybrid machine learning approach that combines:

- FLANN (Fast Library for Approximate Nearest Neighbors)
- PCA (Principal Component Analysis)
- Genetic Algorithm (GA)

The system is designed to improve fingerprint matching accuracy and optimize classification performance using the NIST fingerprint dataset.

---

## 🚀 Features

- Fingerprint image preprocessing
- Feature extraction using PCA
- Fast fingerprint matching using FLANN
- Optimization using Genetic Algorithm
- Multi-class fingerprint classification
- Performance and accuracy evaluation
- Dimensionality reduction and noise handling
